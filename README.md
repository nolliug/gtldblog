# The gTLD Blog

Static relaunch front page for The gTLD Blog.

## Files

- `index.html` — front page
- `style.css` — responsive styling
- `favicon.svg` — site icon
- `robots.txt` — crawler instructions

## GitHub Pages

This site requires no build process.

1. Create a GitHub repository.
2. Upload these files to the repository root.
3. In **Settings → Pages**, select **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`.
5. Save.

GitHub Pages will publish the static website automatically.

If a custom domain is later configured, update the `Sitemap` line in `robots.txt` to the final domain.
